Разбор входящих заявок: n8n + LLM

Сервисная компания получает заявки: ремонт, аренда и монтаж оборудования, вопросы, жалобы, спам. Воркфлоу n8n скрывает контакты, проверяет лимиты, просит модель вернуть JSON по схеме, проверяет ответ кодом и решает, кому отдать заявку.

Заявка

Пример показывает записанный прогон сразу. «Прогнать вживую» отправляет текст в n8n сейчас.
